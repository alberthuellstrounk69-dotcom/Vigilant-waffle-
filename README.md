# Vigilant Waffle - Quantum Console

A quantum-resistant smart contract console for quantum computing applications.

## Overview

Vigilant Waffle is a development platform for quantum resistant smart contract requirements. This project leverages quantum computing frameworks to provide secure, quantum-resistant solutions.

## Features

- 🔐 Quantum-resistant cryptography
- 💻 Smart contract development environment
- ⚛️ Quantum computing integration
- 🛠️ Development console interface

## Getting Started

### Prerequisites

- Docker (for devcontainer setup)
- VS Code with Dev Containers extension
- Python 3.11+

### Setup

1. **Open in Dev Container** (Recommended)
   - Open this repository in VS Code
   - Click "Reopen in Container" when prompted
   - The environment will automatically install required dependencies

2. **Manual Setup**
   ```bash
   pip install -r requirements.txt
   ```
